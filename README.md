# ⭐ Projeto Bitcent ⭐

O Projeto Bitcent é uma aplicação financeira desenvolvida por Marllon Ramos. Esta aplicação permite que os usuários organizem suas finanças de forma simples e eficiente.

**Obs: Para acessar as instruções de execução acesso o arquivo exec [clicando aqui](./exec.md)**

## 📚 Tecnologias Utilizadas 📚

- [React](https://reactjs.org)
- [Next.js](https://nextjs.org/)
- [Firebase](https://firebase.google.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [TailwindCSS](https://tailwindcss.com/)
- [Mantine](https://mantine.dev/)
